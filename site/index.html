Installing

Four steps, and one of them is Apple's fault.

01

Run the command. It builds the native HID module and the mouse driver on your machine, writes a LaunchAgent, and starts the daemon.

02

Grant Accessibility and Input Monitoring to ~/padctl/bin/node. macOS grants these per binary path, which is why the installer freezes its own copy of node rather than using the one Homebrew might upgrade out from under you.

03

Pair the controller. Hold PS and Create until the light bar flashes.

04

The configurator opens by itself. Press a button and it selects there.

Before you install it

What it doesn't do.

—

It can't grant its own permissions. Nothing on macOS can. Any tool claiming one-click setup for this is either lying or shipping a kernel extension.

—

It's a DualSense driver. The HID report is decoded by hand for that pad, which is also why it's called L1R1. Other controllers need their own decoder.

—

The agent profile needs herdr. Sending prompts to a specific pane goes through it. Without herdr you still get the mouse, the clipboard and every system-wide shortcut.

—

It is not a game remapper. If you want to play keyboard-only games with a pad, older tools do that better.
